# Progress Overview Dashboard

A React + Vite application for tracking habits, goals, tasks, and learning sessions.

## Project Setup

The project is located in `C:\Users\durai\Documents\task1`.

### Prerequisites
- Node.js installed.

### Installation & Run
1. Open a terminal in the project folder.
2. Install dependencies:
   ```sh
   npm install
   ```
3. Run the development server:
   ```sh
   npm run dev
   ```
4. Open the link shown (usually `http://localhost:5173`).

## Features
- **Dashboard**: Daily score, summary cards, and weekly progress chart.
- **Habits**: Streak tracking and daily check-ins.
- **Tasks**: Kanban board with drag-and-drop status updates.
- **Goals**: Progress tracking with milestones.
- **Learning**: Study session logging.
- **Focus Mode**: Built-in timer to track focused work.
- **Settings**: Customizable scoring weights and data reset.

## Data Persistence
- Data is stored in your browser's `localStorage`.
- To reset data to default, go to **Settings > Reset to Template**.
